# 📘 TECT-DOCUMENTS

프론트엔드 개발과 관련된 다양한 기술들을 학습하며 정리한 **Technical Documents (TIL)** 저장소입니다.  
CSS 표준, 색상체계, Atomic Design, 프론트엔드 아키텍처 등 실무 기반의 내용을 기록하고 공유합니다. ✨

---

## 📑 저장소 소개

이 저장소는 다음과 같은 목적을 가지고 작성되었습니다:

- 프론트엔드 개발 지식을 체계적으로 정리하고 보관하기 위해
- 새로운 웹 표준 및 기술 흐름을 빠르게 파악하기 위해
- 실무 적용을 위한 개념·예제를 아카이빙하기 위해
- 장기적으로 참고 가능한 기술 문서를 구축하기 위해

모든 문서는 **📂 `/TIL` 디렉터리 내부**에 정리되어 있습니다.

---

## 📂 주요 문서 카테고리

### 🎨 CSS / 디자인 시스템
- CSS Color Module Level 5 정리
- 색상 체계 설명 (RGB, HEX, HSL, LAB, LCH, OKLCH 등)
- 색상 비교표 및 예제
- 디자인 토큰 / 팔레트 설계

### 🧱 UI / 컴포넌트 아키텍처
- Atomic Design
- Functional CSS / Atomic CSS / Utility-First CSS 비교
- Tailwind CSS vs UnoCSS
- Container–Presenter 패턴
- Component-Driven Development
- Domain-Driven UI

### 🧭 프론트엔드 패턴 & 아키텍처
- 프론트엔드 구조 설계 패턴
- MVVM, CDD, DDD UI 구조
- 폴더 구조 설계 예시
- UX/UI 직관성 관련 개념 정리

### 🧪 그 외 Frontend 지식
- 실무 TIL
- 에러 핸들링 & 문제 해결 과정
- 개발 도구 관련 정리
