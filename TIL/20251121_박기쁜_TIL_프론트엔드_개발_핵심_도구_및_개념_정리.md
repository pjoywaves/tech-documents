### 🗓️ 날짜 (Date)

#### [Native]
**Temporal API**
자바스크립트의 새로운 Native 날짜 API로, 기존 `Date` 객체의 여러 문제점을 해결합니다.
-   **완전 불변(immutable):** 한 번 생성된 객체는 변경되지 않습니다.
-   **타임존, DST 완전 지원:** 복잡한 시간대 및 일광 절약 시간 문제를 안정적으로 처리합니다.
-   **파싱이 안정적:** 다양한 날짜 문자열을 일관성 있게 파싱합니다.
-   **날짜 계산 깔끔:** 날짜 및 시간 계산이 직관적이고 오류 발생 가능성이 적습니다.

```javascript
// Plain 계열(타임존 없음)
Temporal.PlainDate;       // YYYY-MM-DD
Temporal.PlainTime;       // HH:MM:SS
Temporal.PlainDateTime;   // YYYY-MM-DDTHH:MM:SS
Temporal.PlainYearMonth;  // YYYY-MM
Temporal.PlainMonthDay;   // MM-DD
```

```javascript
// ZonedDateTime(타임존 포함)
const z = Temporal.ZonedDateTime.from({
  timeZone: "Asia/Seoul",
  year: 2025,
  month: 11,
  day: 21,
  hour: 14,
});
```

```javascript
// Instant - UTC 기준의 절대 시간. 기존의 타임스탬프와 유사합니다.
const now = Temporal.Now.instant();
```

```javascript
// Duration - 기간 계산
const d = Temporal.Duration.from({ days: 3, hours: 4 });
```

#### [Library]
**1. date-fns**
자바스크립트 날짜 유틸리티 라이브러리로, 모듈화된 함수형 스타일을 지향합니다.
-   함수형 스타일: `format()`, `addDays()`, `differenceInDays()` 등 순수 함수로 구성됩니다.
-   로케일 지원이 우수합니다.
-   불변성(immutable)을 유지합니다.

```javascript
import { format, addDays, differenceInDays } from "date-fns";

const now = new Date();

console.log(format(now, "yyyy-MM-dd"));
```

**2. Day.js**
Moment.js의 경량 대체재로, 유사한 문법을 제공하며 가볍습니다.
-   Moment.js 스타일의 직관적인 문법을 제공합니다.
-   작은 번들 크기를 자랑합니다.
-   불변성을 유지합니다.

```javascript
import dayjs from "dayjs";
import utc from "dayjs/plugin/utc"; // UTC 플러그인 예시

dayjs.extend(utc);

console.log(dayjs().format("YYYY-MM-DD"));
```

### 🌐 HTTP 클라이언트

#### [Native]
**1. fetch**
브라우저에 기본 내장된 HTTP 클라이언트로, 표준 Web API입니다.
-   Promise 기반으로 비동기 통신을 처리합니다.
-   `res.json()`과 같이 응답 본문(response body)의 JSON 파싱을 수동으로 처리해야 합니다.
-   네트워크 에러 외의 HTTP 에러(예: 4xx, 5xx)는 `.then` 체인으로 처리되며, `res.ok` 등으로 직접 확인해야 하므로 에러 핸들링이 복잡할 수 있습니다.
-   요청/응답 인터셉터 기능이 없습니다.

```javascript
const res = await fetch("/api/users", {
  method: "GET",
  headers: { "Content-Type": "application/json" }
});

if (!res.ok) throw new Error("Request failed"); // 에러 처리 예시

const data = await res.json();
```

#### [Library]
**1. axios**
외부 HTTP 클라이언트 라이브러리로, 다양한 편의 기능을 제공합니다.
-   요청/응답 **인터셉터**를 제공하여 전역적인 처리(토큰 삽입, 에러 처리 등)가 용이합니다.
-   응답 본문을 자동으로 JSON 파싱합니다.
-   `timeout`, `cancelToken` 등 요청 제어를 위한 편의 기능을 제공합니다.
-   HTTP 에러(4xx, 5xx) 발생 시 Promise `reject`로 처리되어 에러 핸들링이 직관적입니다.

```javascript
// 사용 예시
import axios from "axios";

const res = await axios.get("/api/users");
console.log(res.data);
```

```javascript
// 인터셉터 예시
axios.interceptors.request.use((config) => {
  config.headers.Authorization = "Bearer token";
  return config;
});
```

**2. ky**
Fetch API를 기반으로 한 미니멀한 wrapper 라이브러리입니다.
-   Fetch API의 장점을 유지하면서 사용성을 개선합니다.
-   응답 본문을 자동으로 JSON 파싱합니다.
-   작은 번들 크기로 경량 애플리케이션에 적합합니다.

```javascript
import ky from "ky";

const data = await ky.get("/api/users").json();
```

```javascript
// hooks (axios의 인터셉터와 유사한 기능)
const api = ky.create({
  hooks: {
    beforeRequest: [
      request => {
        request.headers.set("Authorization", "Bearer token");
      }
    ]
  }
});

const data = await api.get("/api/users").json();
```

### 🛠️ 유틸리티(Methods)

#### [Native]
**1. Array Methods**
-   `map()`: 배열의 모든 요소를 변환하여 새로운 배열을 반환합니다.
-   `filter()`: 주어진 조건을 만족하는 요소만 포함하는 새로운 배열을 반환합니다.
-   `reduce()`: 배열의 각 요소에 대해 주어진 리듀서 함수를 실행하여 단일 결과값을 반환합니다.
-   `find()`: 조건을 만족하는 첫 번째 요소를 반환하고, 없으면 `undefined`를 반환합니다.
-   `findIndex()`: 조건을 만족하는 첫 번째 요소의 인덱스를 반환하고, 없으면 `-1`을 반환합니다.
-   `some()`: 배열의 요소 중 하나라도 조건을 만족하면 `true`를 반환합니다.
-   `every()`: 배열의 모든 요소가 조건을 만족하면 `true`를 반환합니다.
-   `flat()`, `flatMap()`: 중첩된 배열을 지정된 깊이만큼 평탄화합니다.
-   `sort()`: 배열의 요소를 정렬합니다 (원본 배열 변경).

**2. Object Methods**
-   `Object.keys()`: 객체의 모든 키(속성 이름)를 문자열 배열로 반환합니다.
-   `Object.values()`: 객체의 모든 값(속성 값)을 배열로 반환합니다.
-   `Object.entries()`: 객체의 모든 `[key, value]` 쌍을 배열로 반환합니다.
-   `Object.fromEntries()`: `[key, value]` 쌍의 배열을 다시 객체로 변환합니다.
-   `Object.assign()`: 하나 이상의 소스 객체로부터 모든 열거 가능한 자체 속성을 대상 객체로 복사합니다 (얕은 복사).
-   `structuredClone()`: 객체의 깊은 복사본을 생성합니다. (Chrome 98+, Node.js 17+ 등)

#### [Library]
**1. lodash / lodash-es**
자바스크립트에서 배열, 객체, 함수 등 다양한 데이터 구조를 조작하는 데 유용한 유틸리티 함수를 제공합니다.
-   `lodash`: 모든 기능이 포함된 단일 번들.
-   `lodash-es`: ES 모듈 형태로 제공되어 트리쉐이킹(Tree Shaking)을 지원, 필요한 함수만 불러와 번들 크기를 줄일 수 있습니다.

**2. ramda**
함수형 프로그래밍 스타일을 강력하게 지원하는 라이브러리입니다.
-   모든 함수가 자동으로 커링(Currying)되어 부분 적용이 용이합니다.
-   `pipe`/`compose` 기반의 데이터 흐름 처리를 강조합니다.
-   순수 함수와 불변성 원칙을 기반으로 합니다.

```javascript
import { pipe, filter, map } from "ramda";

const process = pipe(
  filter((x) => x > 0),
  map((x) => x * 2)
);
```

**3. es-toolkit**
타입스크립트 친화적이며 가벼운 유틸리티 라이브러리입니다.
-   Native, lodash, ramda와 유사한 기능을 제공하지만 타입스크립트 환경에서 더욱 편리합니다.

```javascript
const nums = [1, -2, 3];

// native
const nativeResult = nums.map(n => n * 2);

// lodash
// import _ from "lodash";
// const lodashResult = _.map(nums, n => n * 2);

// ramda
// import * as R from "ramda";
// const ramdaResult = R.map(n => n * 2, nums);

// es-toolkit
import { map } from "es-toolkit";
const esToolkitResult = map(nums, n => n * 2);
```

### 📋 객체 복사 (Object Copy)

#### [Shallow - Native]
**1. Spread Operator (`...`)**
객체의 1단계 속성만 복사합니다. 중첩된 객체는 참조를 공유합니다.

```javascript
const obj = { a: 1, b: { c: 2 } };
const copy = { ...obj };

copy.b.c = 999; // 중첩된 객체 b는 원본과 복사본이 동일한 참조를 가짐

console.log(obj.b.c); // 999 (원본 객체도 변경됨)
```

**2. Object.assign()**
대상 객체에 소스 객체의 열거 가능한 속성을 복사합니다. Spread Operator와 동일하게 얕은 복사입니다.

```javascript
const obj = { a: 1, b: { c: 2 } };
const copy = Object.assign({}, obj);

copy.b.c = 777; // 중첩된 객체 b는 원본과 복사본이 동일한 참조를 가짐

console.log(obj.b.c); // 777 (원본 객체도 변경됨)
```

#### [Deep - Native]
**1. structuredClone()**
주어진 값의 깊은 복사본을 생성합니다. 최신 브라우저 및 Node.js에서 지원합니다.
-   JSON.parse(JSON.stringify())의 단점(Date, Set, Map 등 손실)을 보완합니다.

```javascript
const obj = { a: 1, b: { c: 2 } };
const copy = structuredClone(obj);

copy.b.c = 999; // 복사본의 변경은 원본에 영향을 주지 않음

console.log(obj.b.c); // 2 (원본 객체는 변경되지 않음)
```

**2. JSON.parse(JSON.stringify()) - (비추천)**
객체를 JSON 문자열로 변환한 뒤 다시 파싱하여 깊은 복사를 수행합니다.
-   **주의:** `Date` 객체, `Set`, `Map`, 함수, `undefined` 등 JSON으로 직렬화할 수 없는 타입은 제대로 복사되지 않거나 손실될 수 있습니다.

```javascript
const obj = { a: 1, b: { c: 2 }, d: new Date() };
const copy = JSON.parse(JSON.stringify(obj));

copy.b.c = 123; // 복사본의 변경은 원본에 영향을 주지 않음

console.log(obj.b.c);  // 2
console.log(obj.d);    // Date 객체 (원본)
console.log(copy.d);   // 문자열로 변환된 Date (복사본)
```

#### [Deep - Library]
**1. lodash `cloneDeep`**
lodash 라이브러리에서 제공하는 깊은 복사 함수입니다. 다양한 타입의 객체를 안정적으로 깊은 복사할 수 있습니다.

```javascript
import cloneDeep from "lodash/cloneDeep";

const obj = { a: 1, b: { c: 2 } };
const copy = cloneDeep(obj);

copy.b.c = 500;

console.log(obj.b.c); // 2 (원본 객체는 변경되지 않음)
```

**2. klona**
매우 경량화된 깊은 복사 라이브러리입니다.

```javascript
import { klona } from "klona";

const obj = { a: { b: 1 } };
const copy = klona(obj);
```

**3. rfdc (Really Fast Deep Clone)**
매우 빠른 성능을 자랑하는 깊은 복사 라이브러리입니다.

```javascript
import rfdc from "rfdc";
const clone = rfdc(); // 클로너 함수 생성

const obj = { a: { b: 1 } };
const copy = clone(obj);
```

### 🧩 객체 병합 (Object Merge)

#### [Shallow - Native]
**1. Spread Operator (`...`)**
여러 객체의 속성을 하나로 병합합니다. 동일한 키가 있을 경우, 뒤에 오는 객체의 값이 덮어씁니다. 얕은 병합이므로 중첩된 객체는 참조를 공유하거나 통째로 덮어씌워집니다.

```javascript
const obj1 = { a: 1, b: { x: 10 } };
const obj2 = { a: 2, b: { y: 20 } };

const merged = { ...obj1, ...obj2 }; // obj1의 b가 obj2의 b로 통째로 덮어씌워짐

console.log(merged); // { a: 2, b: { y: 20 } }
```

**2. Object.assign()**
Spread Operator와 동일하게 얕은 병합을 수행합니다.

```javascript
const obj1 = { a: 1, b: { x: 10 } };
const obj2 = { a: 2, b: { y: 20 } };

const merged = Object.assign({}, obj1, obj2); // obj1의 b가 obj2의 b로 통째로 덮어씌워짐

console.log(merged); // { a: 2, b: { y: 20 } }
```

#### [Deep - Library]
**1. lodash `merge`**
lodash 라이브러리에서 제공하는 깊은 병합 함수입니다. 중첩된 객체도 재귀적으로 병합합니다.

```javascript
import merge from "lodash/merge";

const obj1 = { a: { x: 1 }, b: { y: 1 } };
const obj2 = { a: { y: 2 }, c: 3 };

const merged = merge({}, obj1, obj2); // obj1의 a와 obj2의 a가 깊게 병합됨
console.log(merged); // { a: { x: 1, y: 2 }, b: { y: 1 }, c: 3 }
```

**2. deepmerge**
깊은 병합을 전문으로 하는 라이브러리입니다.

```javascript
import deepmerge from "deepmerge";

const obj1 = { a: { x: 1 } };
const obj2 = { a: { y: 2 } };

const result = deepmerge(obj1, obj2);
console.log(result); // { a: { x: 1, y: 2 } }
```

### ⚛️ React Ecosystem (Libraries)

**1. react-dom**
-   **React:** UI를 선언하고 컴포넌트를 정의하는 핵심 라이브러리.
-   **React-dom:** React 컴포넌트를 실제 DOM에 렌더링하는 역할을 담당합니다.
    -   `createRoot()`: React 18부터 도입된 새로운 렌더링 진입점으로, 동시성 렌더링(Concurrent Rendering)을 가능하게 합니다.
    -   `hydrate()`: SSR(Server-Side Rendering) 환경을 지원합니다. 서버에서 렌더링된 정적인 HTML에 클라이언트 측 JavaScript 이벤트를 연결(부여)하는 과정을 의미합니다.
        -   **SSR (Server-Side Rendering):** 웹 페이지를 서버에서 미리 HTML로 렌더링하여 브라우저에 전송하는 방식. 초기 로딩 속도 및 SEO에 유리합니다.
        -   **Hydrate:** 서버에서 생성된 정적 HTML에 클라이언트 측 자바스크립트 코드를 연결하여 동적인 인터랙션 기능을 부여하는 과정입니다.

```tsx
// main.tsx
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

**2. react-router-dom**
React 애플리케이션의 공식 라우팅 라이브러리로, SPA(Single Page Application)에서 페이지 이동을 담당합니다.
-   주요 기능:
    -   `<BrowserRouter>`: HTML5 History API를 사용하여 URL을 관리합니다.
    -   `<Routes>`, `<Route>`: URL 경로에 따라 렌더링할 컴포넌트를 정의합니다.
    -   `useNavigate`, `useParams`, `useLocation` 등의 훅을 통해 프로그래밍 방식의 라우팅 제어 및 URL 정보 접근이 가능합니다.

```tsx
// main.tsx 또는 App.tsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Home from "./Home";
import About from "./About";

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}
```

**3. jest**
JavaScript 및 TypeScript를 위한 강력한 테스트 프레임워크입니다.
-   **단위 테스트:** 개별 함수나 컴포넌트의 동작을 검증합니다.
-   **Mocking 지원:** 실제 객체/함수/네트워크 호출 대신 가짜(fake) 구현을 사용하여 테스트 환경을 격리합니다.
-   **Snapshot 테스트 지원:** 컴포넌트의 렌더링 결과나 함수의 복잡한 출력 결과를 저장해두고, 이후 테스트에서 변경 사항을 자동으로 감지합니다. UI 변경이나 JSON 구조 변경을 빠르게 확인하는 데 유용합니다.

```typescript
// sum.test.ts
import { sum } from "./sum";

test("adds 1 + 2 to equal 3", () => {
  expect(sum(1, 2)).toBe(3);
});
```

**6. zustand**
React를 위한 가볍고 빠르며 유연한 상태 관리 라이브러리입니다. Redux보다 간단한 API를 제공하며 TypeScript 지원이 우수합니다.

```typescript
// store/useCounter.ts
import { create } from "zustand";

interface CounterState {
  count: number;
  inc: () => void;
  dec: () => void; // 추가 학습을 위한 예시
}

export const useCounter = create<CounterState>((set) => ({
  count: 0,
  inc: () => set((state) => ({ count: state.count + 1 })),
  dec: () => set((state) => ({ count: state.count - 1 })),
}));
```

```tsx
// Counter.tsx
import { useCounter } from "./store/useCounter";

function Counter() {
  const { count, inc, dec } = useCounter();
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={inc}>Increment</button>
      <button onClick={dec}>Decrement</button>
    </div>
  );
}
```

**7. clsx**
조건부로 CSS `className` 문자열을 조합하는 데 사용되는 경량 라이브러리입니다. 가독성을 높이고 복잡한 조건부 클래스 로직을 간결하게 만듭니다.

```tsx
import clsx from "clsx";

interface ButtonProps {
  active: boolean;
  disabled?: boolean; // 추가 예시
}

function Button({ active, disabled }: ButtonProps) {
  return (
    <button
      className={clsx(
        "px-4 py-2 rounded",
        active ? "bg-blue-500 text-white" : "bg-gray-300 text-gray-800",
        disabled && "opacity-50 cursor-not-allowed" // disabled가 true일 때만 적용
      )}
      disabled={disabled}
    >
      버튼
    </button>
  );
}
```

## 💡 새롭게 알게 된 점

-   **Rollup:** ESM(ES Module) 중심의 번들러로, 웹팩보다 가볍고 특히 라이브러리 제작에 최적화되어 있습니다. 트리쉐이킹에 강점이 있습니다.
-   **번들러 (Bundler):** 여러 개의 JS/TS, CSS, 이미지 파일 등을 하나(또는 몇 개)의 파일로 묶어(Bundle) 브라우저가 효율적으로 불러오고 실행할 수 있도록 만드는 도구입니다.
-   **MVP (Minimum Viable Product):** '최소 기능 제품'을 의미합니다. 최소한의 핵심 기능만 포함하여 가장 빠르게 시장에 출시 가능한 제품 버전으로, 사용자 반응 및 데이터를 통해 개선 방향을 모색하는 전략입니다.
-   **보일러플레이트 (Boilerplate):** 반복적으로 사용되는 기본 코드 틀이나 설정 파일을 의미합니다. 개발자가 핵심 기능 개발에 집중하기 전에 항상 필요한 구조와 세팅을 제공하여 개발 시작 시간을 단축시켜 줍니다.
-   **GZip:** GNU 프로젝트에서 개발한 ZIP 스타일의 데이터 압축 기술입니다. 데이터를 압축하여 파일 용량을 줄임으로써 서버 전송 속도를 높이고 네트워크 트래픽을 절감하며 애플리케이션 성능을 향상시키는 데 기여합니다. 주로 API 응답, 로그, HTML, JS, CSS 파일 전송에 활용됩니다.
