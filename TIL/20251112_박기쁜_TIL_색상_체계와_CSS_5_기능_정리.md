## 📚 학습 주제
✨ CSS 색상 체계 (RGB, HEX, HSL, HCT, LAB, LCH, OKLCH 등) 및 CSS Color Level 5의 새로운 기능

---

## 🔑 핵심 내용
- 다양한 색상 체계(RGB, HEX, HSL, HCT, LAB, LCH, OKLCH)는 각각 색을 표현하는 방식과 인간의 지각에 대한 정확도에서 차이가 있으며, 프로젝트 요구사항에 따라 적합한 시스템을 선택해야 합니다.
- `OKLCH`는 가장 최신의 지각 기반 색상 모델로, 시각적으로 균일한 색상 변화를 제공하며 점차 브라우저 지원이 확대되고 있으나, 하위 호환성을 위한 폴백(fallback) 전략이 필요합니다.
- CSS Color Level 5는 `color-mix()`, `light-dark()`, `relative colors`, `contrast-color()`와 같은 강력한 함수들을 도입하여 보다 유연하고 동적인 색상 관리를 가능하게 합니다.
- 단기적인 프로젝트에서는 직관적인 `HSL`을, 중장기적인 디자인 시스템 구축에는 접근성과 유지보수 용이성을 고려하여 `OKLCH`를 적용하는 것이 유리할 수 있습니다.

## 📝 상세 내용

### 🎨 다양한 CSS 색상 체계

색상 체계는 색을 수학적으로 표현하는 방식이며, 각각의 장단점을 가집니다.

#### 1. RGB (Red, Green, Blue)
-   **개념:** 디지털 화면의 기본 색상 체계로, 빛의 삼원색(빨강, 초록, 파랑)을 조합하여 색을 표현합니다.
-   **구성:** 빨강(R), 초록(G), 파랑(B) 각 0~255 (8bit) 범위의 값으로 표현됩니다.
-   **예시:** `RGB(255, 0, 0)` (빨강), `RGB(0, 255, 0)` (초록), `RGB(0, 0, 255)` (파랑)
-   **확장:** `RGBA` (Alpha: 투명도)를 통해 투명도 조절 가능. sRGB, Adobe RGB 등의 표준이 있습니다.
-   **장점:** 디지털 디스플레이에 직접 대응하며 표준화되어 널리 사용됩니다.
-   **단점:** 색상 간의 관계(밝기, 채도, 색상 변화)가 직관적이지 않아 원하는 색을 찾기 어렵습니다.

#### 2. HEX (Hexadecimal)
-   **개념:** RGB를 16진수로 표현한 방식입니다.
-   **형식:** `#RRGGBB` 또는 `#RGB` (축약형)
-   **예시:** `#FF0000` (빨강)
-   **특징:** 웹 디자인에서 가장 널리 사용되며, RGB와 동일한 체계지만 표현 방식이 더 간결합니다.

#### 3. HSL (Hue, Saturation, Lightness)
-   **개념:** 인간의 색상 인식(인식 기반 모델)에 가깝게 설계된 색상 모델입니다.
-   **구성:**
    -   **Hue (색상):** 색의 종류 (0~360° 원형 각도)
    -   **Saturation (채도):** 색의 강도 (0~100%)
    -   **Lightness (명도):** 색의 밝기 (0~100%)
-   **예시:** `hsl(0, 100%, 50%)` (빨강), `hsl(120, 100%, 50%)` (초록), `hsl(240, 100%, 50%, 0.5)` (투명한 파랑)
-   **장점:** 색상 변경이 직관적이며, 디자이너가 UI 색상 계열을 만들 때 유용합니다.
-   **단점:** 물리적 정확도가 떨어져 디스플레이 간 색상 편차가 존재할 수 있습니다.

#### 4. HCT (Hue, Chroma, Tone)
-   **개념:** HSL과 유사하나, 인간의 색 지각(perceptual) 기반의 색상 시스템입니다. Material Design 전용으로 개발되었습니다.
-   **구성:**
    -   **Hue (색상):** 0~360°
    -   **Chroma (채도)**
    -   **Tone (밝기):** 0~100
-   **예시:** `HCT(210, 80, 40)` (짙은 파랑), `HCT(210, 80, 90)` (밝은 하늘색)
-   **장점:** 실제 사람의 눈이 인식하는 밝기/채도 차이를 고려하여 접근성(Color Contrast) 확보에 유리합니다.
-   **단점:** 계산이 복잡하며, 일반 CSS에서는 아직 기본적으로 지원하지 않습니다.

#### 5. LAB (CIELAB)
-   **개념:** 인간의 시각적 인식에 맞춘 과학적 색상 체계로, CIE XYZ 색의 물리적 표준을 기반으로 합니다.
-   **구성:**
    -   **L (밝기):** Lightness
    -   **a:** 빨강 <-> 초록 축
    -   **b:** 노랑 <-> 파랑 축
-   **예시:** `Lab(60, 20, -30)`
-   **특징:** 색상 간의 지각적 거리 계산이 가능하여 디자이너보다는 색채학, 인쇄, 접근성 연구 등에서 주로 사용됩니다.

#### 6. LCH (CIELCH)
-   **개념:** LAB 색상 모델을 원형 좌표(Polar coordinates)로 변환한 버전입니다.
-   **구성:**
    -   **L (밝기):** Lightness
    -   **C (채도):** Chroma
    -   **H (색상):** Hue
-   **예시:** `lch(60, 50, 210)` (중간 밝기의 푸른색)
-   **특징:** LAB보다 인간의 감각에 더 직관적이며, 채도와 색상이 명확히 구분됩니다. 하지만 시각 균일성(Perceptual Uniformity)은 완벽하지 않습니다.

#### 7. OKLCH (Lightness, Chroma, Hue)
-   **개념:** 가장 정확하고 최신의 지각(Perceptual) 색상 모델입니다. CIELAB를 개선한 모델입니다.
-   **구성:**
    -   **L (밝기):** 0~1
    -   **C (채도):** 0~0.5
    -   **H (색상):** 0~360°
-   **예시:** `oklch(0.75 0.2 210)` (밝은 파랑)
-   **특징:** 사람의 시각적 인식과 거의 동일하게 밝기/채도를 계산합니다. CSS Color Level 4부터 브라우저 기본 지원이 확대되고 있습니다.
-   **장점:** 명도, 채도 변화가 시각적으로 균일하며, 디자이너, 접근성 엔지니어, UI 토큰 시스템에서 선호됩니다.
-   **단점:** IE와 같은 구버전 브라우저에서는 지원되지 않으며, 색상 범위 변환 시 약간의 손실이 발생할 수 있습니다.

### 🌐 색상 체계의 브라우저 호환성 및 권장 사항

-   **RGB:** 모든 브라우저에서 완벽하게 지원됩니다.
-   **HSL:** 대부분의 모던 브라우저에서 지원됩니다.
-   **OKLCH:** 2023년부터 주요 브라우저에서 지원하기 시작했지만, 완전한 지원을 위해서는 폴백(fallback) 색상을 제공하는 것이 필요합니다.

```css
.brand-button {
  /* 폴백(Fallback) RGB 색상 */
  background-color: rgb(0, 122, 255);
  /* 현대적인 브라우저를 위한 OKLCH */
  background-color: oklch(65% 0.2 240);
}
```

**다른 레퍼런스들은 어떤 색상 체계를 따르는가?**
-   대부분의 웹 프로젝트에서는 `HEX` 또는 `RGBA`를 주로 사용합니다. (예: `hzems`의 경우 90% HEX / 10% RGBA 사용)
-   다른 지각 기반 색상 체계는 아직 보편적으로 사용되지 않는 경우가 많습니다.

**우리는 어떤 색상 체계를 따라야 하는가?**
-   `RGB`나 `HEX`는 직관적이지 않고, 값 변경 시 모든 코드를 수정해야 하는 불편함이 있습니다.
-   `OKLCH`는 브라우저 지원이 아직 완전하지 않아 폴백 코드를 작성하는 번거로움이 있습니다.

**결론:**
-   **중장기적인 프로젝트나 디자인 시스템**에서는 `OKLCH` 색상 체계를 도입하는 것이 장기적인 관점에서 유리합니다. (뛰어난 접근성 및 색상 관리 용이성)
-   **단기적이며 빠른 퍼포먼스가 중요한 프로젝트**에서는 `HSL`을 적용하는 것이 직관적인 색상 변경 및 충분한 브라우저 지원 측면에서 효율적일 수 있습니다.

### 🚀 CSS Color Level 5의 새로운 기능 (CSS5)

CSS Color Level 5는 공식 릴리스 버전은 아니지만, 개발 중인 강력한 색상 관련 기능들을 포함하고 있습니다.

#### 1. `<color>`의 확장

##### 1.1 `transparent`
-   **개념:** 완전히 투명한 색을 정의합니다. `rgba(0, 0, 0, 0)`과 동일합니다.
```html
<div style="background-color: blue;">
  이 컨텐츠의 배경색은 blue 입니다.
  <button style="background-color: transparent;">
    버튼의 색상은 transparent 입니다.
  </button>
</div>
```

##### 1.2 `currentColor`
-   **개념:** `color` 속성의 현재 계산된 값을 상속받아 사용합니다.
```html
<div style="color: blue;">
  이 title의 color는 blue 입니다.
  <p style="border: 1px solid currentColor;">
    이 컨텐츠의 border는 blue 입니다.
  </p>
</div>
```

#### 2. `color-mix()`
-   **개념:** 두 가지 색을 특정한 색 공간(color-space) 기준으로 비율에 따라 섞는 함수입니다.
-   **문법:** `color-mix(in <color-space>, <color1> <percentage>, <color2> <percentage>)`
    -   `<color-space>`: 혼합이 이루어질 색 공간 (예: `srgb`, `lch`, `lab`, `oklab`, `xyz`)
    -   `<percentage>`: 상대 가중치. 합이 100%가 아니어도 자동 정규화됩니다.
-   **예제 1: 회색 혼합**
```css
.box {
  /* 흰색 60%, 검정 40%를 sRGB 색 공간에서 섞음 == 중간 회색(#999999) */
  background: color-mix(in srgb, white 60%, black);
}
```
-   **예제 2: 색 공간에 따른 결과 차이**
```css
.box1 { background: color-mix(in srgb, red 50%, blue); } /* 보라 + 청색 */
.box2 { background: color-mix(in lch, red 50%, blue); }  /* 더 선명한 보라 */
```
    -   같은 색을 섞어도 색 공간에 따라 결과가 다르게 나타날 수 있습니다.

#### 3. Relative Colors (상대 색상)
-   **개념:** 기존에는 `hsl(210 50% 50%)`처럼 절대값만 지정 가능했지만, 이제 `from var(--base)`와 같이 다른 색을 기준으로 계산할 수 있습니다.
-   **문법:** `<color-function>(from <base-color> <components>)`
-   **예제 1: 기준색의 밝기 조절**
```css
:root { --brand-color: hsl(210 60% 50%); }

.button {
  /* 기준색에서 밝기를 +10% */
  background: hsl(from var(--brand-color) h s calc(l + 10%));
}
```
-   **예제 2: 보색(complementary) 만들기**
    -   색상 각도 `h`를 180도 더하면 정확히 반대색(보색)을 만들 수 있습니다.
```css
:root { --accent: lch(60% 80 40); }

.border { border-color: lch(from var(--accent) l c calc(h + 180)); }
```

#### 4. `light-dark()` - 다크 모드 대응 색상 선택
-   **개념:** 사용자 시스템의 다크/라이트 모드 설정에 따라 자동으로 적절한 색을 반환하는 함수입니다. `@media (prefers-color-scheme)`를 직접 사용하지 않아도 됩니다.
-   **예제:**
```css
body {
  background-color: light-dark(white, #121212); /* 라이트 모드: white, 다크 모드: #121212 */
  color: light-dark(black, white);             /* 라이트 모드: black, 다크 모드: white */
}
```

#### 5. `contrast-color()` - 대비 자동 계산
-   **개념:** 배경색을 기준으로 WCAG(웹 콘텐츠 접근성 지침) 기준에 맞는 읽기 쉬운 텍스트 색상을 자동으로 선택합니다.
-   **예제:**
```css
.card {
  background: var(--brand-color);
  color: contrast-color(var(--brand-color)); /* --brand-color에 따라 읽기 쉬운 텍스트 색상 자동 선택 */
}
```

#### 6. `device-cmyk()` - 인쇄용 색상 정의
-   **개념:** 디지털 화면용이 아닌 인쇄 장치용 색상(CMYK)을 정의할 수 있는 함수입니다. 웹보다는 PDF, CSS Print 등에서 주로 사용됩니다.
-   **예제:**
```css
.print-page {
  /* CMYK - (0, 50, 100, 0) 밝은 주황색 인쇄용 잉크 비율 */
  color: device-cmyk(0% 50% 100% 0%);
}
```

#### 7. `@color-profile` - 사용자 정의 색 공간
-   **개념:** 외부 ICC 프로파일을 등록하여 특정 색 공간을 정의하고, `color()` 함수에서 사용할 수 있게 합니다.
-   **예제:**
```css
@color-profile --p3 {
  src: url("display-p3.icc");
}
.box {
  background: color(--p3 0.5 0.2 0.8);
}
```

## 💡 새롭게 알게 된 점
- **ICC 프로파일 (ICC Profile):** 특정 장치 또는 보기 조건에 대한 색상 정보가 포함된 데이터 셋입니다. 인쇄 작업 시 디자인 의도와 실제 인쇄 색상의 일치를 보장하며, 색상 공간 또는 색 영역을 설명하는 데 필수적인 역할을 합니다.

---

## 🤔 궁금한 점 / 추가 학습 필요
- CSS Color Level 5에 새롭게 도입된 기능들은 아직 실험적이거나 브라우저 지원이 완벽하지 않은 경우가 많으므로, 실제 프로젝트 적용 시 호환성 및 폴백 전략에 대한 추가 학습과 검증이 필요할 것 같습니다.
- 현재 주로 사용하는 `flexbox` 외에 `CSS Grid`와 같은 다른 레이아웃 관련 CSS 문법에 대해서도 심도 있는 학습을 통해 다양한 웹 디자인 요구사항에 대응할 수 있는 역량을 키워야 할 것 같습니다.
